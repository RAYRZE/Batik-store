# 🛍️ Batik Store

**Batik Store** adalah aplikasi web toko online yang dirancang untuk menjual berbagai produk batik khas Indonesia. Proyek ini dibangun untuk memberikan pengalaman berbelanja kain dan pakaian batik yang modern, responsif, dan mudah digunakan.

---

## 🚀 Fitur Utama

- **Katalog Produk:** Menampilkan koleksi kain, pakaian, dan aksesori batik dengan gambar dan deskripsi lengkap.
- **Keranjang Belanja (Shopping Cart):** Memudahkan pengguna untuk menambahkan, mengubah jumlah, atau menghapus item sebelum checkout.
- **Desain Responsif:** Tampilan yang optimal diakses baik dari perangkat seluler (mobile) maupun desktop.
- **Navigasi Cepat & Ringan:** Antarmuka pengguna (UI) yang bersih dan intuitif.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Deployment / Hosting:** Vercel
